## 输入与输出

输入：页面清单URL/title/topic/type，来源正文及现有链接；可选关键词映射。

输出：internal-links.csv及建议段落；已验证链接与待验证链接分开。

## 工作步骤

1. 识别来源段落的用户问题以及可承接的目标页；没有内容证据时不要只靠标题硬匹配。
2. 选择能补充细节或推进决策的链接，锚文本来自上下文，避免重复堆精确关键词。
3. 核对链接是否已有、是否自链及语言市场是否匹配；失效与跳转状态必须有检查证据。
4. 输出每条来源URL、原段位置、目标URL、建议锚文本、替换后句子和理由。
5. 目录缺页列内容机会，不能把虚构URL混入可直接执行的链接清单。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-internal-links`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
